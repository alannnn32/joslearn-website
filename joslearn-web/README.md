# JosLearn Web

Sistem informasi absensi dan nilai rapor untuk SMA Negeri 1 Rejoso.

## Struktur
- `config/` - konfigurasi database dan sistem
- `assets/` - CSS, JavaScript, dan gambar
- `controllers/` - logika bisnis
- `models/` - query database
- `views/` - antarmuka Admin dan Guru
- `uploads/` - bukti surat izin/sakit
- `index.php` - entry point/router

## Catatan
File-file di dalam paket ini merupakan skeleton/project structure awal.
Implementasi database, autentikasi, CRUD, geofencing, QR, dan rapor dapat ditambahkan berikutnya.
